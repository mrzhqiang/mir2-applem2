# 测试规则和最佳实践

## 单元测试
- 为关键业务逻辑编写单元测试
- 测试正常流程和异常流程
- 测试边界条件
- 使用断言验证结果
- 示例：
  ```pascal
  procedure TestUserLogin;
  begin
    // 测试正常登录
    Assert(Login('testuser', 'password') = True, '登录应该成功');
    
    // 测试错误密码
    Assert(Login('testuser', 'wrong') = False, '错误密码应该失败');
    
    // 测试空用户名
    Assert(Login('', 'password') = False, '空用户名应该失败');
  end;
  ```
