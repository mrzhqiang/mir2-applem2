# 性能优化规则

## 内存管理
- 及时释放不需要的对象
- 避免频繁创建和销毁对象，考虑对象池
- 使用引用计数管理共享资源
- 注意字符串拼接的性能（使用 TStringBuilder 或预分配）
- 避免内存碎片化

## 字符串操作
- 避免在循环中进行字符串拼接
- 使用预分配或 TStringList 处理大量字符串
- 注意 AnsiString 和 WideString 的性能差异
- 示例：
  ```pascal
  // 不好：频繁拼接
  for i := 1 to 1000 do
    Result := Result + IntToStr(i);
  
  // 好：使用 TStringList
  List := TStringList.Create;
  try
    for i := 1 to 1000 do
      List.Add(IntToStr(i));
    Result := List.Text;
  finally
    List.Free;
  end;
  ```

## 数据库操作
- 使用参数化查询避免 SQL 注入
- 批量操作优于单条操作
- 合理使用事务
- 避免 N+1 查询问题
- 使用连接池管理数据库连接

## 网络通信
- 批量发送数据包减少网络往返
- 使用缓冲区减少系统调用
- 合理设置 Socket 缓冲区大小
- 避免阻塞操作，考虑异步处理
- 实现心跳机制保持连接

## 图形渲染
- 减少不必要的重绘
- 使用双缓冲避免闪烁
- 合理使用纹理和资源缓存
- 优化绘制顺序和裁剪区域
- 注意 DirectX 资源管理

## 算法优化
- 选择合适的数据结构（数组、列表、哈希表）
- 避免不必要的循环嵌套
- 使用缓存减少重复计算
- 考虑空间换时间的策略

## 代码优化建议
- 避免过早优化，先确保功能正确
- 使用性能分析工具找出真正的瓶颈
- 优化热点代码（执行频率高的代码）
- 保持代码可读性，不要过度优化
