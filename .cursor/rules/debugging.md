# 调试规则和最佳实践

## 日志记录
- 使用统一的日志记录机制
- 关键操作必须记录日志
- 日志包含时间戳和操作上下文
- 使用不同日志级别：DEBUG、INFO、WARNING、ERROR
- 示例：
  ```pascal
  WriteLog('用户登录', Format('用户名: %s, IP: %s', [UserName, IP]));
  ```

## 异常处理
- 所有可能出错的操作都要有异常处理
- 记录异常详细信息（消息、堆栈）
- 不要静默吞掉异常
- 使用 try..except 捕获异常，try..finally 释放资源
- 示例：
  ```pascal
  try
    // 操作代码
  except
    on E: Exception do
    begin
      WriteLog('错误', Format('操作失败: %s', [E.Message]));
      // 处理异常
    end;
  end;
  ```

## 断点调试
- 在关键逻辑处设置断点
- 检查变量值和对象状态
- 使用条件断点提高效率
- 调试完成后移除调试代码

## 性能调试
- 使用性能分析工具定位瓶颈
- 记录关键操作的执行时间
- 注意内存使用情况
- 检查是否有内存泄漏

## 网络调试
- 记录网络通信数据包
- 检查 Socket 连接状态
- 验证数据包格式和内容
- 注意超时和重连机制

## 常见问题排查
- 检查对象是否为 nil
- 验证数组边界
- 确认字符串编码（ANSI/Unicode）
- 检查文件路径和权限
- 验证数据库连接状态
