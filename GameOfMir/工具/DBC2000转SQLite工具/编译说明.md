# DBC2000 转 SQLite3 工具 - 编译说明

## SQLite3.dll 部署

本工具需要 `sqlite3.dll` 文件才能运行。程序会自动从程序目录加载 DLL。

## 编译步骤

直接编译项目即可，无需额外步骤。

## DLL 部署

### 方法 1：复制到程序目录（推荐）

将 `sqlite3.dll` 文件复制到编译后的 exe 文件所在目录。

例如：
```
DbcToSqliteTool.exe
sqlite3.dll          ← 放在这里
```

### 方法 2：从 Common 目录获取

如果 `GameOfMir\Common\sqlite3.dll` 存在，可以：
1. 复制到程序目录
2. 或者将程序放在 `GameOfMir\工具\DBC2000转SQLite工具\` 目录下运行

## 获取 sqlite3.dll

如果 `sqlite3.dll` 文件不存在，可以从 SQLite 官网下载：

1. 访问：https://www.sqlite.org/download.html
2. 下载 "Precompiled Binaries for Windows" 中的 `sqlite-dll-win32-x86-*.zip`
3. 解压后将 `sqlite3.dll` 复制到程序目录

## 工作原理

程序启动时会：
1. 设置 DLL 搜索路径为程序目录
2. 从程序目录加载 `sqlite3.dll`
3. 如果找不到 DLL，会显示错误信息

## 故障排除

### 问题：运行时提示找不到 sqlite3.dll

**解决方案**：
1. 确保 `sqlite3.dll` 文件存在于程序目录
2. 检查文件名称是否正确（区分大小写）
3. 检查文件是否损坏（尝试重新下载）
4. 确保 DLL 版本与程序兼容（32位程序需要32位DLL）

### 问题：DLL 版本不匹配

**解决方案**：
- 确保下载的 DLL 版本与程序架构匹配（32位或64位）
- 本工具通常需要 32位版本的 DLL
