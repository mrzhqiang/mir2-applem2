# 传奇游戏引擎装备凝练系统设计方案

## 系统概述

装备凝练系统是一个装备强化系统，允许玩家使用凝练材料对装备进行多次强化，每次凝练都有一定的成功率，成功后装备获得属性提升。

## 核心规则

### 1. 凝练次数
- 装备默认0次凝练状态（无凝练）
- 可通过物品数据库设置最大凝练次数，默认8次
- 每次成功凝练后，凝练次数+1

### 2. 凝练材料
- 预定义新类型物品道具作为凝练材料
- 材料分品阶，参考强化材料系统
- 品阶范围：1-13阶（可手动修改上限）
- 材料支持合成：4份相同品阶→1份更高品阶（100%成功率）

### 3. 凝练过程
- 每次凝练必须使用3份材料
- 材料品阶可以不同
- 根据材料品阶和凝练次数计算成功率

### 4. 成功率计算公式
```
基础成功率 = 50%（1阶材料）
品阶加成 = 每阶+10%
次数惩罚 = 每次凝练-20%

单份材料成功率 = (基础成功率 + (品阶-1)*10%) - (当前凝练次数-1)*20%
总成功率 = min(100%, max(0%, 材料1成功率 + 材料2成功率 + 材料3成功率))
```

### 5. 计算示例
- 第1次凝练，3份1阶材料：50%+50%+50%=150%→100%
- 第2次凝练，3份1阶材料：30%+30%+30%=90%
- 第2次凝练，3份2阶材料：40%+40%+40%=120%→100%
- 第3次凝练，3份2阶材料：(50%+(2-1)*10%-(3-1)*20%)*3=60%

## 核心算法实现

### 1. 成功率计算

```pascal
function CalculateRefineSuccessRate(
  RefineLevel: Byte; 
  Materials: array of TRefineMaterial
): Integer;
var
  i: Integer;
  nTotalRate: Integer;
  nMaterialRate: Integer;
begin
  Result := 0;
  nTotalRate := 0;
  
  // 计算每份材料的成功率
  for i := Low(Materials) to High(Materials) do begin
    // 基础成功率 + 品阶加成 - 次数惩罚
    nMaterialRate := g_RefineConfig.nBaseSuccessRate + 
                     (Materials[i].btGrade - 1) * g_RefineConfig.nGradeBonus - 
                     RefineLevel * g_RefineConfig.nLevelPenalty;
    
    // 累加到总成功率
    nTotalRate := nTotalRate + nMaterialRate;
  end;
  
  // 成功率限制在0-1000之间 (‰)
  if nTotalRate > 1000 then
    Result := 1000
  else if nTotalRate < 0 then
    Result := 0
  else
    Result := nTotalRate;
end;
```

### 2. 材料合成

```pascal
function SynthesizeMaterial(
  SourceGrade: Byte; 
  Count: Integer
): TRefineResult;
var
  TargetGrade: Byte;
  RequiredCount: Integer;
begin
  Result := rr_Failed;
  
  // 检查是否可以合成
  if SourceGrade >= g_RefineConfig.btMaxGrade then begin
    Result := rr_MaxLevel;
    Exit;
  end;
  
  RequiredCount := 4; // 默认4份合成1份
  if Count < RequiredCount then begin
    Result := rr_MaterialLack;
    Exit;
  end;
  
  TargetGrade := SourceGrade + 1;
  
  // 合成成功率100%
  Result := rr_Success;
end;
```

### 3. 装备凝练

```pascal
function RefineEquipment(
  PlayObject: TPlayObject;
  Equipment: pTUserItem;
  Materials: array of TRefineMaterial
): TRefineResult;
var
  nSuccessRate: Integer;
  nRandom: Integer;
  i: Integer;
begin
  Result := rr_Failed;
  
  // 检查系统是否启用
  if not g_boRefineSystemEnabled then begin
    Result := rr_SystemDisabled;
    Exit;
  end;
  
  // 检查是否已达最大凝练次数
  if Equipment.RefineInfo.btRefineLevel >= Equipment.RefineInfo.btMaxRefineLevel then begin
    Result := rr_MaxLevel;
    Exit;
  end;
  
  // 检查材料数量
  if Length(Materials) <> g_RefineConfig.nMaterialRequired then begin
    Result := rr_MaterialLack;
    Exit;
  end;
  
  // 计算成功率
  nSuccessRate := CalculateRefineSuccessRate(Equipment.RefineInfo.btRefineLevel, Materials);
  
  // 随机判定
  nRandom := Random(1000);
  if nRandom < nSuccessRate then begin
    // 凝练成功
    Inc(Equipment.RefineInfo.btRefineLevel);
    ApplyRefineBonus(Equipment);
    Result := rr_Success;
  end else begin
    // 凝练失败
    Result := rr_Failed;
  end;
  
  // 消耗材料
  ConsumeMaterials(PlayObject, Materials);
end;
```

### 4. 凝练属性加成

```pascal
procedure ApplyRefineBonus(Equipment: pTUserItem);
var
  StdItem: pTStdItem;
  RefineLevel: Byte;
  BonusRate: Double;
begin
  StdItem := UserEngine.GetStdItem(Equipment.wIndex);
  if StdItem = nil then Exit;
  
  RefineLevel := Equipment.RefineInfo.btRefineLevel;
  if RefineLevel = 0 then Exit;
  
  // 凝练加成比例 (每级+5%)
  BonusRate := RefineLevel * 0.05;
  
  // 应用到装备属性
  with Equipment.RefineInfo do begin
    // 攻击力加成
    if StdItem.DC > 0 then
      wRefineAttrib[0] := Round(StdItem.DC * BonusRate);
    if StdItem.MC > 0 then
      wRefineAttrib[1] := Round(StdItem.MC * BonusRate);
    if StdItem.SC > 0 then
      wRefineAttrib[2] := Round(StdItem.SC * BonusRate);
      
    // 防御力加成
    if StdItem.AC > 0 then
      wRefineAttrib[3] := Round(StdItem.AC * BonusRate);
    if StdItem.MAC > 0 then
      wRefineAttrib[4] := Round(StdItem.MAC * BonusRate);
  end;
end;
```

## 实现优势

### 1. 系统特点
- **渐进式强化** - 多次凝练逐步提升装备属性
- **策略性选择** - 不同品阶材料的搭配策略
- **风险控制** - 成功率随凝练次数递减，增加挑战性
- **资源循环** - 材料合成系统促进经济循环

### 2. 平衡性设计
- **成功率递减** - 防止无限制强化
- **材料消耗** - 控制强化成本
- **上限限制** - 最大凝练次数限制
- **品阶区分** - 不同品质材料的价值体现

### 3. 扩展性
- **配置驱动** - 所有参数可通过配置调整
- **模块化设计** - 易于扩展新的凝练类型
- **数据库支持** - 支持动态配置和管理
